# خطة الظهور في Google — للموقع النهائي (تُطبق بعد اعتماد التصميم)
ملاحظة: لا يُنفذ أي بند الآن — كل الشغل الحالي على المختبر فقط.

## الأساسيات (عند البناء النهائي)
1. عناوين quantità: title/description عربية فريدة لكل صفحة (وليس نفس الوصف مكرراً كالقديم).
2. HTML دلالي: h1 واحد لكل صفحة + تسلسل h2/h3 + alt عربي لكل صورة + lang="ar" dir="rtl".
3. ملفات: sitemap.xml + robots.txt + canonical لكل صفحة.
4. بيانات منظمة Schema.org: LocalBusiness/Contractor (الاسم، الهاتف 0551215610، الرياض، ساعات العمل) + FAQ إن وجدت.
5. Open Graph/Twitter cards بصورة غلاف حقيقية (بدل preview.jpg القديمة).
6. الأداء: next/image بأحجام صحيحة + lazy + ضغط الصور الكبيرة (pic15/16/17) + تقليل JS.
7. روابط داخلية بين الأقسام + عناوين URL عربية/إنجليزية ثابتة تحافظ على روابط القديم (/cars ... إلخ) أو redirect 301 منها.
8. Search Console + خرائط Google Business لاحقاً (خارج نطاق الكود).

## ما يجب تجنبه (أخطاء القديم)
- نصوص مكررة حرفياً بين الصفحات.
- صور بدون alt.
- عناوين Title عامة واحدة لكل الصفحات الفرعية (كانت ناقصة).
